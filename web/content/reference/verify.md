# verify-setup.mjs

Verifies a repository generated by the harness.

```bash
node scripts/verify-setup.mjs <target>
```

## Output

One line per check:

```text
PASS  .harness.json is valid JSON with required fields — type web, CI full
FAIL  CI and build workflows match the declared depth — missing ci.yml
```

Then a summary:

```text
13/13 checks passed.
```

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Every check passed |
| `1` | At least one check failed |

## The 13 checks

See [Verification](../concepts/verification.md) for the full list.

## Notes

- `.agent` not initialized is a note, not a failure.
- Existing project sections such as `Tech stack` are reported, not rejected.
- Verification runs from the harness tree; the target does not need the
  verifier.
