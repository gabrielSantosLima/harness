# Locked decisions

These rules apply to every generated project. They are recorded in
[`setup/decisions.md`](https://github.com/gabrielSantosLima/harness/blob/main/setup/decisions.md).

## Language

- Code, identifiers, comments, documentation, commits and release notes are in
  English, unless the project explicitly configures another release-notes
  language.

## Commits

- Conventional Commits: `<type>(<scope>): <description>`.
- Imperative, lowercase, no trailing period, at most 72 characters.
- Allowed types: `feat`, `fix`, `refactor`, `chore`, `docs`, `test`, `perf`,
  `build`, `ci`, `style`.

## Attribution

- No AI attribution anywhere: no `Co-Authored-By`, no "Generated by", no tool,
  agent or session names.

## Git safety

- Stage explicit paths; never `git add -A`, `git add .` or `git commit -a`.
- Never force-push.
- Never move, delete or reuse a release tag.
- Never commit secrets, environment files, build output or local notes.

## Releases

- Releases only through the configured workflow.
- Quality gates must pass before tagging.
- One release-notes template: `docs/RELEASE_TEMPLATE.md`.

## Data

- Never invent data, sources or dependencies.
- Unknown fields use `null` and the gap is recorded.

## Autonomy

- Never commit or push unless the user asked.

## Changing a decision

Read [Changing a decision](../contributing/templates.md) before editing the
contract.
