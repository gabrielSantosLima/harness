# Roadmap

## Available today

- Five project types: `web`, `mobile`, `desktop`, `library`, `data`.
- Setup modes: `new`, `adopt`, `update`, `audit`.
- `AGENTS.md`, `.harness.json` and `.agent/skills`.
- CI, build, release and Pages deploy workflows.
- Tags-only or file-based versioning.
- Release notes in English, Portuguese or Spanish.
- Four project skills plus `project-setup`.
- End-to-end tests and new/adopt/update pilots.

## Planned

- An optional `architecture` skill.
- More optional skills as recurring workflows emerge.
- Versioned documentation, if the docs need to match multiple releases.
- Translations of the documentation site.

## Explicitly deferred

- Stack-specific templates.
- Architecture enforcement.
- Dependency management.
- Hosting beyond GitHub Pages.
